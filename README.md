# Transport failures or deliberate placements? A statistical re-examination of the road moai of Rapa Nui

Manuscript and fully reproducible analysis re-examining the statistical evidence in

> Lipo, C.P., Hunt, T.L. (2025). The walking moai hypothesis: Archaeological evidence,
> experimental validation, and response to critics. *Journal of Archaeological Science* 183, 106383.

All analyses use the data and code deposited by Lipo and Hunt
(https://github.com/clipo/moai_walking, MIT licence; Zenodo doi:10.5281/zenodo.17329904).
The analysis scripts were developed with the assistance of Claude (Anthropic).

## Contents

| Path | Content |
|---|---|
| `main.tex`, `main.pdf` | The paper. Tables are embedded in `main.tex`; it only needs the `figures/` folder (compile with `pdflatex` two or three times; no BibTeX needed) |
| `highlights.txt` | Highlights for submission (5 bullet points, at most 85 characters each) |
| `tables/*.tex` | Table bodies generated by `code/make_tables.py`; their content is embedded verbatim in `main.tex` |
| `figures/*.pdf` (`*.png`) | Figures generated by `code/make_figures.py` (`fig4_housner` is Fig. B.1 of the paper) |
| `data/` | Extracts of the repository of Lipo and Hunt (CSV) and the 3D model of statue 12-220-01 |
| `results/` | Every numerical result (CSV/JSON) behind the tables, figures and text |
| `code/` | Python scripts (see below) |

## Reproduce

```bash
pip install -r requirements.txt
# optional: rebuild data/ from a clone of the repository of Lipo and Hunt
git clone https://github.com/clipo/moai_walking.git
python code/prepare_data.py moai_walking
# all analyses, figures and tables (about 1.5 minutes)
python code/run_all.py
pdflatex main.tex && pdflatex main.tex && pdflatex main.tex
```

Random seeds are fixed, so a rebuild from scratch reproduces every table exactly.
If the analyses are re-run and a table changes, copy the new `tables/*.tex` content into the
corresponding table of `main.tex`.

## Scripts

| Script | What it does |
|---|---|
| `common.py` | Paths, quarry centroid, dataset definitions (D84, D62, D61, D56), probable duplicates |
| `prepare_data.py` | Builds `data/` from the repository of Lipo and Hunt |
| `s1_reproduction.py` | Reproduces the test battery of their Supplementary Table S1; quantifies the AIC scale artefact |
| `distance_models.py` | Maximum-likelihood comparison of seven distance laws (with left truncation) |
| `gof.py` | Anderson-Darling (parametric bootstrap) and Kolmogorov-Smirnov tests of the exponential law |
| `survival.py` | Failure rates by distance with delivered ahu statues as censored observations; Kaplan-Meier |
| `breakage.py` | Breakage of road moai versus distance (Fisher exact tests, logistic regression, sensitivity analysis) |
| `copula_size_distance.py` | Rank correlations, Cramer-von Mises independence test, Gaussian/Frank/Clayton/Gumbel copulas with rotations, tail coefficients, hypergeometric tests, detection-probability simulation |
| `terrain_orientation.py` | Table 1 of Lipo and Hunt: association, two-parameter logit model, margins versus road terrain |
| `mechanics.py` | Mass and centre of mass from the 3D model, Eq. 1 of Lipo and Hunt, rocking period, Froude scaling, rate and power checks |
| `morphometrics.py` | Published and corrected Fig. 2 contrast; adjustment for statue length |
| `make_figures.py`, `make_tables.py` | Figures and LaTeX tables |
| `run_all.py` | Runs everything |

## Dataset definitions

* **D84**: the 84 "road moai" used in Fig. 12 and the tests of the Supplementary Information of Lipo and Hunt
  (61 locations of the database road class + 23 added statues that the database classifies as quarry or ahu statues).
* **D62**: all statues classified as road moai in the source database (Schumacher 2013), as in the abstract of Lipo and Hunt.
* **D61**: D62 with one record per location (records 411 and 701 share their coordinates).
* **D56**: D61 without five probable duplicate records (Hunt/Lipo records within 12 m of a Shepardson record).

The author line and the bracketed declarations of `main.tex` are placeholders.
